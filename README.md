# 📦 Mood Coffee

> Sistem informasi manajemen pesanan dan ulasan pelanggan berbasis web.

---

## ✨ Fitur Utama

- 👤 **Autentikasi & Pelanggan**: Registrasi dan manajemen data pelanggan.
- 💳 **Pembayaran (Payment)**: Simulasi/pencatatan transaksi pembayaran.
- 🚚 **Tracking & Delivery**: Pelacakan status pengiriman secara real-time.
- ⭐ **Review & Ulasan**: Fitur penambahan ulasan dan feedback layanan.
- ⚙️ **Status Update**: Pembaruan status pesanan dan tipe layanan.

---

## 🛠️ Tech Stack

- **Backend**: PHP Native
- **Frontend**: HTML5, CSS3
- **Database**: MySQL / MariaDB
- **Web Server**: Apache (XAMPP)

---
